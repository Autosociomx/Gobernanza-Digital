# Matriz de lectura

| CI | Calidad observada | Madurez | Interpretación |
|---|---|---|---|
| pasa | deuda detectada | EXPERIMENTAL | técnicamente ejecutable, todavía requiere mejoras |
| pasa | sin hallazgos actuales | LAB_MOCK | sigue siendo laboratorio; CI no cambia alcance |
| falla | alta | VALIDATED | existe una regresión nueva; la evidencia previa no desaparece, pero el SHA actual no cumple |
| pasa | alta | PILOT | apto para continuar el piloto solo si existen además las aprobaciones/evidencias del piloto |

La matriz evita convertir un único color en una afirmación sobre todo el sistema.
