# Alcance de esta intervención

Esta rama modifica infraestructura de integración continua, evidencia y gobernanza de cambios. No cambia deliberadamente lógica de negocio de ORBE, Context.OS, SOATM o Evidence.OS.

El objetivo es construir una base de medición fiable antes de usar la CI para impulsar optimizaciones adicionales en aplicación, rendimiento y arquitectura.

Los nuevos gates deben probarse en esta rama y revisarse por señal. No se recomienda fusionar únicamente porque el conjunto termine verde; deben revisarse también falsos positivos, duración y utilidad diagnóstica.
