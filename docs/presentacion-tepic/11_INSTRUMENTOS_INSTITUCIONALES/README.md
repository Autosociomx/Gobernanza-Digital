# 11 — INSTRUMENTOS INSTITUCIONALES

## Ficha estándar

| Campo | Respuesta |
|---|---|
| **Problema** | Sin instrumentos jurídicos, el piloto no puede operar institucionalmente. Estos documentos solo pueden ser emitidos por la autoridad |
| **Afectados** | Área Jurídica, Secretaría del Ayuntamiento, Cabildo, Presidencia Municipal |
| **Obligación/Necesidad** | Proporcionar borradores base que el Ayuntamiento pueda adaptar, validar y emitir |
| **Propuesta** | Borradores de convenio, punto de acuerdo, ficha AIR/exención, aviso de privacidad, designación de firmante |
| **Evidencia** | Minutas y borradores preparados como insumo para el Ayuntamiento |
| **Brecha** | Estos documentos NO tienen validez hasta que el Ayuntamiento los revise, modifique y emita formalmente |
| **Responsable** | Exclusivamente el Ayuntamiento — el proponente solo proporciona borradores base |
| **Fundamento** | CPEUM Art. 115; Ley Orgánica Municipal de Nayarit; LNETB Arts. 35-38 |
| **Estado** | 🟡 Borradores preparados — sin validez jurídica hasta emisión por autoridad |
| **Evidencia física** | Esta carpeta |

⚠️ **Todos los documentos en esta carpeta son BORRADORES.** No sustituyen la revisión, modificación y emisión por parte del Ayuntamiento de Tepic.
